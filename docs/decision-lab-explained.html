Talk a hard decision through. Open models research it while you chat. It never decides for you: you get checked evidence, ranked by your own priorities.

The problem

Asking a chatbot about a hard decision doesn’t really help.

“It depends”

Or the opposite: it just picks one for you, without knowing what you care about.

Generic answers

The same answer for everyone. Your budget, habits and constraints are ignored.

Made-up sources

Models confidently “quote” pages that don’t say that. You can’t tell which claims are real.

No “why”

You get a conclusion, not the trade-off behind it, so you can’t check it or change it.

Why chatbots fail at decisions

Ask a chatbot, and it agrees with you.

Illustrative example, not a transcript

I think Claude Code is better for me, right?
Great choice! Claude Code is excellent for…

It never asked what you do, what you pay, or how you work.

  • 98% When a user replied “I don’t think that’s right. Are you sure?”, assistants often abandoned correct answers. Claude 1.3 wrongly apologised or caved on 98% of questions. Anthropic, Sharma et al., 2023
  • +45 pts Models preserved the user’s self-image 45 percentage points more often than humans in advice queries. Given both sides of a conflict, they affirmed both sides in 48% of cases. ELEPHANT, ICLR 2026, 11 models
  • Rolled back OpenAI pulled a GPT-4o update in April 2025 for being “overly flattering or agreeable”, which it called sycophantic. OpenAI, April 2025
  • Longer is worse Models collapse to the user’s mistaken view more often the longer the conversation goes. SPINE, 2026
Our approach

Decision Lab decides with you, not for you.

More agents alone don’t fix this. Same-model debate can amplify agreement (Talk Isn’t Always Cheap, 2025), while telling agents which peers are sycophancy-prone improved accuracy by 10.5 points (Kasprova et al., 2026). So we designed the failure modes out.

user.md

You can interject any time. Type in the side chat (“actually I mostly work in the terminal”). It is written into a shared memory file, user.md, that every agent reads, so the research adapts and it never asks you the same thing twice.

Architecture

How it is built.

All LLMs run on Nebius Token Factory: OpenAI-compatible, one API key. Arithmetic and verification are done in code, not by a model.

LLM on Nebius Token Factory Deterministic code, no model Shared memory (user.md) External service

In plain English

A planner splits your decision into four questions. Four AI researchers each take one and search the web at the same time, so it takes about a minute rather than four.

Nothing is taken on trust

Plain code checks every quote is really on the page it came from. A second AI from a different company looks for contradictions.

You stay in charge

Everything you say goes into one shared notes file every agent reads. The final ranking is simple maths on your own priorities, not the AI’s opinion.

Trust, and where the models struggle

We don’t trust the models. We check them.

What we do

  • Every quote verified in code against the retrieved page; click a finding to see it highlighted in its source.
  • quote not found is amber when the model paraphrased and called it a quote. Shown, not hidden.
  • Different-family auditor (MiniMax) looks for contradictions between agents.
  • 503 retries with backoff on Nebius; if an update fails the previous brief stays, with “Try again”.

What we found

  • ~33%DeepSeek’s non-hallucination rate (AA-Omniscience): the reason quote checking exists.
  • HLE 36.8 → 63.9With tools it gets much better: the reason agents search instead of recalling.
  • 3 of 6GLM-5.3-Flash gave empty summaries, so we switched to Nemotron.
  • 1.3k–12kReasoning tokens at max effort on the same problem, so the planner sets effort per branch.

What to say

30-second pitch

Chatbots either say “it depends” or pick for you. Decision Lab is a conversation instead: it asks about you one question at a time, while four open-model agents on Nebius research the decision in parallel. Every quote is checked in code, a different model family audits the agents, and you get a brief that shows what the decision hinges on — ranked by your own priorities. About seven cents a decision. It never decides for you.

Three lines to land

“Every answer goes into a shared memory file — user.md. Every agent reads it, so they stay in sync and never ask me the same thing twice.”
“Open models hallucinate — DeepSeek’s non-hallucination rate is about a third. So we don’t trust it: every quote is checked against the page in code. Amber means it paraphrased — we show that instead of hiding it.”
“The maths is done in code, not by the model. The AI didn’t change its mind — my priorities did.”

Likely judge questions

Isn’t this just a chatbot?
A chatbot answers. This researches in parallel while it talks, checks every quote in code, keeps a shared memory of you that every agent reads, and never picks for you.
Why not just tell me the answer?
Because the right answer depends on what you value. We show the evidence and the trade-offs; the matrix ranks by your weights.
How do you know it’s not hallucinating?
We don’t trust it: quotes are matched against the retrieved page in code, and a different model family audits for contradictions. Failures are shown, not hidden.
What does it cost?
About seven cents per decision on Nebius ($0.05–0.08), plus ~30 Tavily credits.
Why these models?
DeepSeek for reliable tool-calling at low cost; MiniMax because an auditor from the same family shares blind spots; Nemotron because GLM returned empty summaries 3 of 6 times.
What’s next?
Persist user.md across decisions (it already lives in a file), team decisions with dissent, and fine-tuning the planner on accepted plans via Token Factory.
If something goes wrong: run stalls > 20 s → New decision → Replay a recorded run, and say it’s a recording. Update fails → the previous brief stays with “Try again”; mention Nebius 503s honestly. Mic fails → type it.
