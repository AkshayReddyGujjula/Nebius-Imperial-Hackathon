Decision Lab

Talk a hard decision through. Open models research it while you chat. It never decides for you — it shows you what the decision hinges on, with checked evidence, ranked by your own priorities.

Today’s demo: “Claude Code or Codex — which coding agent fits me?”
1 · The problem

Asking a chatbot about a hard decision doesn’t really help

“It depends”

Or the opposite: it just picks one for you, without knowing what you care about.

Generic answers

The same answer for everyone. Your budget, habits and constraints are ignored.

Made-up sources

Models confidently “quote” pages that don’t say that. You can’t tell which claims are real.

No “why”

You get a conclusion, not the trade-off behind it — so you can’t check it or change it.

3 · Architecture (technical)

How it is built

All LLMs run on Nebius Token Factory — OpenAI-compatible, one API key. Arithmetic and verification are done in code, not by a model.

5 · Trust, and where the models struggle

We don’t trust the models — we check them

What we do

  • Every quote verified in code against the retrieved page; click a finding to see it highlighted in its source.
  • quote not found — amber when the model paraphrased and called it a quote. Shown, not hidden.
  • Different-family auditor (MiniMax) looks for contradictions between agents.
  • 503 retries with backoff on Nebius; if an update fails the previous brief stays, with “Try again”.

What we found

  • DeepSeek’s non-hallucination rate is ~33% (AA-Omniscience) — the reason quote checking exists.
  • With tools it gets much better: HLE 36.8 → 63.9 — the reason agents search instead of recalling.
  • GLM-5.3-Flash gave empty summaries 3 of 6 times → switched to Nemotron.
  • Max effort is noisy: 1.3k–12k reasoning tokens on the same problem → planner sets effort per branch.

8 · Rehearsal cheat-sheet

What to say

30-second pitch

Chatbots either say “it depends” or pick for you. Decision Lab is a conversation instead: it asks about you one question at a time, while four open-model agents on Nebius research the decision in parallel. Every quote is checked in code, a different model family audits the agents, and you get a brief that shows what the decision hinges on — ranked by your own priorities. About four cents a decision. It never decides for you.

Three lines to land

“Every answer goes into a shared memory file — user.md. Every agent reads it, so they stay in sync and never ask me the same thing twice.”
“Open models hallucinate — DeepSeek’s non-hallucination rate is about a third. So we don’t trust it: every quote is checked against the page in code. Amber means it paraphrased — we show that instead of hiding it.”
“The maths is done in code, not by the model. The AI didn’t change its mind — my priorities did.”

Likely judge questions

Isn’t this just a chatbot?
A chatbot answers. This researches in parallel while it talks, checks every quote in code, keeps a shared memory of you that every agent reads, and never picks for you.
Why not just tell me the answer?
Because the right answer depends on what you value. We show the evidence and the trade-offs; the matrix ranks by your weights.
How do you know it’s not hallucinating?
We don’t trust it: quotes are matched against the retrieved page in code, and a different model family audits for contradictions. Failures are shown, not hidden.
What does it cost?
About four cents per decision on Nebius, plus ~30 Tavily credits.
Why these models?
DeepSeek for reliable tool-calling at low cost; MiniMax because an auditor from the same family shares blind spots; Nemotron because GLM returned empty summaries 3 of 6 times.
What’s next?
Persist user.md across decisions (it already lives in a file), team decisions with dissent, and fine-tuning the planner on accepted plans via Token Factory.
If something goes wrong: run stalls > 20 s → New decision → Replay a recorded run, and say it’s a recording. Update fails → the previous brief stays with “Try again”; mention Nebius 503s honestly. Mic fails → type it.
